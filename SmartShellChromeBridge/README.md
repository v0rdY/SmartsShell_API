# SmartShell Bridge

1. Откройте `chrome://extensions` в рабочем Chrome.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите эту папку `SmartShellChromeBridge`.
5. Один раз обновите открытую вкладку `admin.smartshell.gg`.

Значок `ON` означает, что токен передан приложению. `OFF` означает, что приложение не запущено, а `!` — что вход в SmartShell ещё не завершён.
